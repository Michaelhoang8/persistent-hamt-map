Bitmap-indexed branches

slot = (hash >>> shift) & 31
bit = 1 << slot
index = bitCount(bitmap & (bit − 1))

Packed children contain only occupied slots. Five hash bits are consumed at each level; the last level uses the remaining two bits.

Identity accounting

IdentityHashMap-backed sets measure shared/new/retired nodes. “Retired” means absent from the child version; an older root may still retain that object. Node IDs are deterministic inspection labels, not heap addresses.

04 / HASH AND DELETION EDGE CASES

Full-hash collisions stay explicit

Equal hashes, unequal keys

hash("Aa") = hash("BB")
= 0x00000840

A collision node retains both distinct String keys. Lookup compares the whole key. Replacing or removing one entry leaves the other value intact.

The collision workload includes 64 different Aa/BB-family keys with the same complete 32-bit hash. Collision scanning remains linear in that bucket.

Deep shared prefixes

0x00000001

These generated String hashes share 30 low bits. They exercise all seven levels, including a negative signed hash.

Two warm-ups, seven measured repetitions, alternating implementation order. Retained lists escape through a volatile reference; checksums are consumed. Setup and full correctness checks are outside timing. GC/JIT/system noise remain uncontrolled; this is not JMH or a general production speedup claim.

The baseline copies even on absent deletes. HAMT can return the same instance for a no-op. This compares the stated full-copy version strategy, not the best possible JDK implementation or another persistent-map library.

The map implementation contains leaves, collision arrays and bitmap-indexed branches; it does not wrap a HashMap. Independently copied HashMaps serve as test/replay oracles and the explicit benchmark baseline.

Contract: no null keys; well-formed UTF-16 keys up to 128 code units; integer values −1,000,000 through 1,000,000; up to 16,384 entries per map. Empty keys, Unicode, negative hash codes and bitmap slot 31 are covered. No custom equality, hash mixing, concurrent mutation, transient builder or physical-memory instrumentation is supplied.
